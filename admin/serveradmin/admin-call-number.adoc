Call Number Prefix and Suffix
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
[[_prefix_and_suffix]]

If your library uses prefixes or suffixes in call numbers, you can build a standard list which 
will be displayed as drop down options when creating or editing call number records.

This is how a prefix or suffix list appears when creating or editing a call number.

image::images/admin/call-number-prefix-1.png[scaledwidth="75%",alt="Create Call Number Suffix"]

[[_create_call_number_prefix_suffix]]
Create a Call Number Prefix or Suffix
+++++++++++++++++++++++++++++++++++++

. Go to *Administration -> Server Administration -> Call Number Prefixes* or *Call Number Suffixes*.
+
To view the prefixes or suffixes for your library, enter your library code into the Library Selector. Multi-branch libraries can enter the system and then check the box to display the descendants.
. Click *New Call Number/Volume Prefix* or *New Call Number/Volume Suffix*. 
+
image::images/admin/call-number-prefix-2.png[scaledwidth="75%",alt="Create Call Number Suffix"]
+
. *Enter* the value for the Label.
** The Label Sort Key is generated based on the Label you assign, and the Label Sort Key changes if the Label changes.
. Choose your library as the Owning Library.
. Click *Save*.
+
image::images/admin/call-number-prefix-3.png[scaledwidth="75%",alt="Create Call Number Suffix"]

[[_edit_call_number_prefix_suffix]]
Edit a Call Number Prefix or Suffix
+++++++++++++++++++++++++++++++++++
. *Check* the check box of the prefix or suffix to be edited.
. Click *Edit Selected*.
+
image::images/admin/call-number-prefix-edit-1.png[scaledwidth="75%",alt="Create Call Number Suffix"]
+
. Edit the value for Label, then click *Save*.
+
image::images/admin/call-number-prefix-edit-2.png[scaledwidth="75%",alt="Create Call Number Suffix"]

[CAUTION]
=========
Changing a call number prefix or suffix immediately updates all call numbers using the prefix or suffix. While this may be desired, it can also cause a mismatch with physical item labels.
=========

[[_delete_call_number_prefix_suffix]]
Delete a Call Number Prefix or Suffix
+++++++++++++++++++++++++++++++++++++
. *Check* the check box of the prefix or suffix to be deleted.
. Click *Delete Selected*.
+
image::images/admin/call-number-prefix-delete-1.png[scaledwidth="75%",alt="Create Call Number Suffix"]
+
. When the pop-up appears, click *Confirm* to confirm deletion.
+
image::images/admin/call-number-prefix-delete-2.png[scaledwidth="75%",alt="Create Call Number Suffix"]

[CAUTION]
=========
Prefixes and suffixes can only be deleted if they have not been applied to a call number. The prefix or suffix must be removed from every call number it is in use with before the prefix or suffix can be deleted.

You may also need to log out and back in again for the deleted prefix or suffix to disappear as an option.
=========
