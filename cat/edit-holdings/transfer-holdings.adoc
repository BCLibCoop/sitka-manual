Transferring Holdings
~~~~~~~~~~~~~~~~~~~~~

Sometimes holdings need to be moved to a different bibliographic record or items need to be moved to a new existing call number.
Transferring these holdings enables them to be moved without losing circulation data, as would happen if the holding was deleted
and recreated.

[TIP]
=====
For multi-branch libraries, if you wish to permanently transfer holdings between branches this should be done by updating 
the item attributes for _Circulating Library_ and _Owning Library_. See xref:_the_holdings_editor[] for
more information.
=====


[[_transfer_holding]]
Transferring Holdings
^^^^^^^^^^^^^^^^^^^^^

Holdings may need to be transferred if the bibliographic record they are attached to doesn't match the item in hand or
there is a better record in the catalogue that could be used instead.


[TIP]
=====
In cases where there is a better record cataloguers should assess whether holdings should be transferred or whether the
two records should be merged together to reduce duplication in the catalogue and so that all libraries with holdings
attached get the benefit of the better record. See xref:_merging_bibliographic_records[].
=====
 
. Find the record you would like to move your holdings to. 
. From the *Mark for* drop down menu, select *Holding Transfer*.
+
image::images/cat/transfer-holding-1.png[]
+
. A confirmation message reading _Holding Transfer Target Set_ will appear at bottom right of the screen.
+
[NOTE]
======
Once you set a transfer target it will be kept until a new target is marked or the record marks are reset
by going to *Mark for* -> *Reset Record Marks*.

image::images/cat/transfer-reset-record-marks-1.png[]
======
+
. Retrieve the record that the holdings you would like to transfer are currently attached to.
. Click the _Holdings View_ tab and select the call number you want to transfer. 
+
image::images/cat/transfer-holding-2.png[]
+
. From the *Actions* menu select *Transfer Holdings to Marked Destination*.
+
image::images/cat/transfer-holding-3.png[]
+
. The screen automatically refreshes and the selected holdings no longer appear in the grid.
. Manually refresh the record you transferred the holdings to and confirm they now display there as expected.
. Check the original record to see if there are any title holds for your library. If there are follow the instructions 
in xref:_transferring_title_holds[] to transfer them to the new record as well. Any item or call number level holds will need
to be cancelled and re-placed on the new record.


[TIP]
========
Evergreen will merge call numbers together if the transferred call number matches a call number for your library on the
new record.
========

[[_transfer_holdings_another_branch]]
Transferring Holdings to Another Branch
++++++++++++++++++++++++++++++++++++++++


When you want to transfer all items under one call number to another
library under the same title, you use the *Transfer Holdings* function. Evergreen will transfer both
the call number record and all items under it to the new library.

. Find the destination or target record. On *Mark for* dropdown list, select *Holding Transfer*.
+
image::images/cat/transfer-holding-1.png[]
+
. Confirmation appears at bottom right of the screen.
+
image::images/cat/transfer-holding-2.png[]
+
NOTE: Transfer target is kept until it is reset (via *Reset Record Marks* on *Mark for* list) or a new target is marked.
+
. Go to *Holdings View* of the source title, and select the destination library.
.. You may need to select *Show Empty Libs* to see your destination.
+
image::images/cat/transfer-holding-5.png[]
+
Click *Actions* dropdown list. Scroll down to *Mark*. Select *Mark Library/Call Number as Transfer Destination*.
+
image::images/cat/transfer-holding-6.png[]
+
. Confirmation appears at the bottom right corner of the screen.
+
. Find the source title. Select the source volume on *Holdings View*.
+
image::images/cat/transfer-holding-7.png[]
+
. Click *Actions* dropdown list. Scroll down to *Transfer*. Select
*Transfer Holdings to Marked Destination*.
+
image::images/cat/transfer-holding-3.png[]
+
. Confirmation appears at bottom right of the screen.


[TIP]
=======
If the destination library has a call number with the same call number, the call numbers will be merged during the transfer.
=======

[[_transfer_item]]
Transferring Items
^^^^^^^^^^^^^^^^^^

You may wish to transfer specific items under one call number to another call number or transfer all
items under one call number to a different call number; this can be done within a single record or between
records. 

[TIP]
=====
Call number changes within a record can also be done by updating the call number in 
the holdings editor. See xref:_holdings_details[].
=====

. Retrieve the record that the call number you would like to transfer to is currently attached to.
. Click the _Holdings View_ tab and select the call number you want to transfer to. 
+
image::images/cat/transfer-holding-4.png[]
+
. From the *Actions* menu select *Library/Call Number as Transfer Destination*.
+
image::images/cat/transfer-holding-5.png[]
+
. If the item you wish to transfer is attached to a different record, retrieve that record.
. Click the _Holdings View_ tab and select the item you want to transfer. 
. From the *Actions* menu select *Transfer Items to Marked Destination*.
+
image::images/cat/transfer-holding-6.png[]
+
. The screen automatically refreshes and the selected item will display under its new call number 
or no longer appear in the grid if it has been moved to a call number attached to another record.
. If the item has been moved between records, check the original record to see if there are any title holds for your 
library. If there are follow the instructions in xref:_transferring_title_holds[] to transfer them to the new record as well.
Any call number level holds will need to be cancelled and re-placed on the call number.

[NOTE]
======
You can also use an item bucket to transfer a number of items at once. See xref:_working_with_items_in_a_bucket[].
======
